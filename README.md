# QLDA hạ tầng: giao diện web

Trang tĩnh của hệ thống quản lý dự án hạ tầng. Chỉ có giao diện; dữ liệu nằm ở Google Sheet qua Apps Script và chỉ truy cập được sau khi đăng nhập Google và được Phòng Kỹ thuật cấp quyền.

Không chứa bí mật: `config.js` chỉ có địa chỉ Apps Script và OAuth Client ID (đều công khai theo thiết kế). Tạo bằng `npm run pages` từ kho nguồn riêng; đừng sửa tay.
